# A5 基层安全生产智能体

> 第十一届华为 ICT 大赛 · 创新赛 · 赛题二（基于华为云 AgentArts 的 Agent 设计和应用）
> 选题：粉尘涉爆重大事故隐患判定 —— 隐患识别 · 定性 · 处置建议 · 文书生成

## 一句话

把《工贸企业重大事故隐患判定标准》（应急管理部令第 10 号）从**文本**变成**可逐条执行的判定引擎**：
模型只负责把执法人员说的话整理成结构化字段，判定由确定性代码执行，给用户看的每个字都来自代码返回的 `render`。

**判定链路上不准出现检索，也不准让模型自由发挥。** 这是整个方案的护城河。

## 快速开始

只跑工具集，不需要平台、不需要网络、不需要装任何第三方依赖：

```bash
cd app/mcp
python -m dust_hazard_mcp      # 自检：6 个工具 + 六种状态机
python tests/test_mcp.py       # 端到端自测，期望「通过 40 项，失败 0 项」
```

装成命令：

```bash
cd app/mcp && pip install .
dust-hazard-mcp                # MCP 服务（stdio）
dust-hazard-http --port 8080   # HTTP 外壳 + OpenAPI
```

六个工具：

| 工具 | 用途 |
|---|---|
| `judge` | 现场事实 → 构成 / 不构成 / 待核实（三态） |
| `list_clauses` | 列条款清单 |
| `clause_detail` | 条款原文、判定条件、证据要求、追问问句 |
| `clause_search` | 执法人员口语 → 候选条款（匹配不到就说未命中） |
| `clause_check` | 条款结构校验（入库前的闸门） |
| `render_doc` | 按模板出文书草稿 + 要素完整性校验 |

详细参数、返回结构、三种接入方式、平台注册步骤见 [`app/mcp/README.md`](app/mcp/README.md)。

- 引擎更新后重新导出覆盖，跑一遍 `python tests/test_mcp.py`，在 `app/mcp/CHANGELOG.md` 记一笔

## 已知边界

- 只接入「粉尘涉爆」一个领域（10 条条款），其它领域走 `need_industry` 提示
- 不做 AI 看图定隐患：大量隐患是缺失型（未设置、未落实），照片拍不出来
- 系统只给建议与依据，不作出行政决定；文书固定带「草稿，须经法定程序与审批后生效」水印与签名位
- 判定只有两种结论加一种待核实，**没有「隐患等级」这种说法**，部令里不存在分级
