| 项 | 状态 |
|---|---|
| 跑分脚本 | ⬜ 未开始（交付物 4，P0） |

现有可复用的半成品：

| 文件 | 作用 | 覆盖 |
|---|---|---|
| `app/mcp/tests/test_mcp.py` | 端到端断言（拉起 MCP 子进程） | 40 项 |

这两个都是**功能自测**，不是**效果评测**。效果评测要做的是：

```
读用例集 → 逐条调用判定 → 比对期望结论 → 汇总指标 → 输出表格
```

## 计划产出（验收标准：一条命令跑完出表格）

| 文件 | 内容 |
|---|---|
| `golden_cases.json` | 金标用例集：`{id, query, industry, facts, expect_verdict, expect_stage, expect_clause_ids}` |
| `run_eval.py` | 读用例 → 调 `/api/judge` 或引擎 → 出表 |
| `report.md` / `report.csv` | 跑分结果（准确率、漏判率、误报率、条款命中率） |

## 指标口径（按方案深度设计建议书 6.4）

| 指标 | 定义 | 目标 |
|---|---|---|
| 判定准确率 | 与专家标注一致的比例 | ≥ 95%（规则引擎应为 100%） |
| **重大隐患漏判率** | 实际构成重大却判为非重大/待核实 | ≤ 5%，**必须单列** |
| 严重误报率 | 非重大却判为重大 | ≤ 10% |
| 条款引用准确率 | 命中条款与期望一致 | ≥ 92% |
| 单次耗时 | 输入→结论 | ≤ 10 秒（本地实测 18ms） |

## 用法（建好后）

```bash
cd app/mcp
python ..\..\eval\run_eval.py --cases ..\..\eval\golden_cases.json
```
