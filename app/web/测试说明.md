# 粉尘涉爆隐患判定 Demo · 给测试者的说明

> 3 分钟能测完。如果你只读一段，读第 2 节就好。

## 1. 这是什么

基层安全生产执法用的**隐患判定辅助工具**。执法人员用大白话说现场情况，系统给出：

- 是否**构成重大事故隐患**（构成 / 不构成 / 待核实）
- 依据是《工贸企业重大事故隐患判定标准》哪一条，附条文原文
- 认定这一条需要哪些证据
- 还有哪些信息没问清，下一步该问什么

**它不是**：AI 看图识隐患、自动执法、替代执法人员作决定。

## 2. ⚠️ 最重要的一条：现在测的是「本地判定引擎」

页面右上角那条状态胶囊写着：

```
🟢 同源判定引擎 · 18ms（平台 Key 未配置）
```

意思是：**这一版跑的是本地判定引擎，还没有连华为云 AgentArts 平台**（平台的 API Key 还没配）。

所以：

- ✅ 判定结论、依据链、追问，**都是真的、可用的**
- ❌ 看不到"平台在工作"的痕迹，**这属于正常现象，不是功能缺失**

判定逻辑和平台上的那份是**同一份代码**（平台「判断」节点导出的逐字副本），所以结论一致。接入平台只是把大模型自动抽取那一步接上，判定结果不会变。

## 4. 建议这样测（3 分钟）

**先点左上方四个快捷按钮**，这是最主要的三条路径：

| 按钮 | 应该看到 |
|---|---|
| 木质家具 · 积尘严重 | 🔴 构成重大事故隐患 · 第十一条第（十）项 |
| 干式除尘 · 无锁气卸灰 | 🔴 构成 · 第十一条第（六）项 |
| 只说粉尘 · 信息不足 | 🟡 待补充信息 + 2 条追问 |
| 湿式除尘 | 🟡 待核实 |

**然后自己在输入框里说几句**，试试：

- "我们是做木质家具的，车间木屑积得比较厚，清理制度也没落实"
- "除尘器是干式的，没看到泄爆片"
- "铝镁粉尘，打磨车间，除尘系统是正压的"

**再看右边三个 Tab**：

- **判定卡片**：结论 + 结论文本（这段文字由判定引擎原样返回，一个字没改）
- **依据链**：命中条款、待核实条款、不适用条款、本轮追问
- **诊断**：走了哪条链路、耗时、引擎版本、原始返回数据

## 5. 请注意

1. **我这台电脑必须开着**。这是本地做服务器，电脑休眠或关机，公网地址就打不开了（聊天窗口找我要一次就行）
2. **别填真实企业和真实姓名**。测试一律用"某木质家具厂""张三"这类模拟信息
3. **别说"这是几级隐患"**。判定只有三态：构成 / 不构成 / 待核实。《工贸企业重大事故隐患判定标准》里**不存在隐患分级**，问了也不会有答案——这是专业口径，不是功能缺失
4. **自由输入会有"抽不准"的情况**。本地没有大模型，是用关键词粗略抽取的。说得越具体越准；说得太笼统（比如"有点脏"），系统会老实回"待核实"并反问你——**这是设计如此，不是 bug**
5. **别做压测**。公网走的是免费穿透，并发 5、带宽 1 Mbps，2~3 个人同时用没问题，一堆人同时刷会卡
6. **公网地址别外传**。没有访问口令，拿到链接谁都能用。别贴到公开帖子、群公告、PPT 里
